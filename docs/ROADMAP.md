# Baba — Roadmap & Working Method

## The method we repeat for EVERY task (always the same)
1. I tell you what we're doing and why.
2. I give you ONE action to do.
3. You do it.
4. We verify together that it worked.
5. Only then we move to the next step.
If something errors: paste it, we fix it before continuing. No question is too basic.
You are the director of works; Claude Code does the heavy coding.

## The stages (one at a time; each must work before the next)

0. **Setup** — check what's on the PC, install Claude Code + essentials. Just setup.
1. **Brain replies** — start Baba's engine and get a reply from the keyboard. "It's alive."
2. **PC capabilities** — connect email, calendar, files. Daily usefulness, fast.
3. **Memory + Obsidian** — long-term memory + the Obsidian vault as shared knowledge base.
4. **Finance mentor** — tutor mode for stocks / crypto / commodities, starting from zero,
   plus a market DATA SOURCE (begin with a FREE feed/API). No broker/real account needed.
5. **Real estate** — portfolio tracking, rental analysis vs local listings, scenarios.
   (Mentor first: learn to read ANY deal; then apply to his own properties.)
6. **Proactive Baba** — alerts/briefings that arrive on their own (e.g. watchlist news).
7. **Voice + HUD face** — connect the mic and the reactive sphere (prototypes/baba_hud.html).
8. **His own stuff** (optional) — databases, IoT. The bespoke touch.

Stages 1-3 already give a useful Baba. Everything else stacks on top, no rush.

## Golden rule
One stage at a time, and it must actually work before the next. Resist adding new ideas
mid-build — the plan is already rich. Realize a piece before expanding.
